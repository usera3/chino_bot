## 🔍 如果连接失败

### 检查 1: 确认同一网络

**在手机上**：
- 设置 > WiFi > 查看当前连接的 WiFi 名称

**在电脑上**：
```bash
networksetup -getairportnetwork en0
```

两个 WiFi 名称必须一致！

### 检查 2: 测试连接

在手机浏览器中访问：
```
http://10.89.92.155:7070/test_step1
```

如果能看到网页，说明网络连通性没问题。

### 检查 3: 查看服务器日志

```bash
tail -f /tmp/robotic_arm_server.log
```
