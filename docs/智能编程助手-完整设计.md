# 智能编程助手 - 完整设计方案

## 🎯 目标

让机器人像 Windsurf、Kiro、Cursor 一样，能够：
- 读写代码文件

- 自动修复错误

## 📋 三阶段实施计划

### 阶段 1：基础代码操作能力（3-5 天）

**目标**：让机器人能够读写文件、执行命令

#### 新增工具

1. **read_project_file** - 读取项目文件
   ```python
   输入: file_path (相对于项目根目录)
   输出: 文件内容
   安全: 只能读取项目目录内的文件
   ```

2. **write_project_file** - 写入项目文件
   ```python
   输入: file_path, content
   输出: 写入结果
   安全: 只能写入项目目录，需要确认
   ```

3. **list_project_files** - 列出项目文件
   ```python
   输入: directory (可选)
   输出: 文件列表（树形结构）
   安全: 只显示项目目录
   ```

4. **search_in_files** - 在文件中搜索
   ```python
   输入: pattern, file_pattern (可选)
   输出: 匹配结果（文件名 + 行号 + 内容）
   安全: 只搜索项目目录
   ```

5. **execute_command** - 执行 bash 命令
   ```python
   输入: command, working_dir (可选)
   输出: 命令输出
   安全: 命令白名单 + 用户确认
   ```

#### 安全机制

```python
# 1. 路径限制
PROJECT_ROOT = "/path/to/chino_bot"
ALLOWED_PATHS = [PROJECT_ROOT]

# 2. 命令白名单
ALLOWED_COMMANDS = [
    "python", "pip", "pytest", "ls", "cat", "grep",
    "git status", "git diff", "git log"
]

# 3. 用户确认（危险操作）
REQUIRE_CONFIRMATION = [
    "write_project_file",  # 写入文件
    "execute_command",     # 执行命令
]

# 4. 权限控制
ADMIN_USERS = ["123456789"]  # 你的 QQ 号
```

#### 使用示例

```
用户: 帮我看看 bot.py 的内容
机器人: [调用 read_project_file("bot.py")]

用户: 在所有 Python 文件中搜索 "Butler"
机器人: [调用 search_in_files("Butler", "*.py")]

用户: 运行一下测试
机器人: [调用 execute_command("pytest test_butler.py")]
```

## 🔒 安全设计

### 1. 多层防护

```python
# 第一层：路径验证
def validate_path(path: str) -> bool:
    real_path = os.path.realpath(path)
    return real_path.startswith(PROJECT_ROOT)

# 第二层：权限检查
def check_permission(user_id: str, operation: str) -> bool:
    if operation in DANGEROUS_OPS:
        return user_id in ADMIN_USERS
    return True

# 第三层：操作审计
def audit_log(user_id: str, operation: str, details: dict):
    log_entry = {
        "timestamp": datetime.now(),
        "user_id": user_id,
        "operation": operation,
        "details": details
    }
    save_to_audit_log(log_entry)

# 第四层：用户确认
def require_confirmation(operation: str) -> bool:
    if operation in REQUIRE_CONFIRMATION:
        # 发送确认消息给用户
        return wait_for_user_confirmation()
    return True
```

### 2. 命令白名单

```python
SAFE_COMMANDS = {
    # 查看类
    "ls", "cat", "head", "tail", "grep", "find",
    
    # Python 类
    "python", "python3", "pip", "pytest",
    
    # Git 类（只读）
    "git status", "git log", "git diff", "git show",
    
    # 测试类
    "pytest", "python -m pytest",
}

DANGEROUS_COMMANDS = {
    "rm", "mv", "cp",  # 文件操作
    "sudo", "su",      # 权限提升
    "chmod", "chown",  # 权限修改
    "kill", "pkill",   # 进程管理
}
```

### 3. 沙箱执行

```python
def execute_in_sandbox(command: str) -> str:
    """在沙箱环境中执行命令"""
    # 设置资源限制
    resource.setrlimit(resource.RLIMIT_CPU, (10, 10))  # 10秒 CPU
    resource.setrlimit(resource.RLIMIT_AS, (512*1024*1024, 512*1024*1024))  # 512MB 内存
    
    # 设置超时
    result = subprocess.run(
        command,
        shell=True,
        capture_output=True,
        timeout=30,  # 30秒超时
        cwd=PROJECT_ROOT
    )
    
    return result.stdout.decode()
```
