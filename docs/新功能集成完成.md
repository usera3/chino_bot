1. 访问 [Tavily 官网](https://tavily.com) 注册账号
2. 获取 API 密钥（每月 1,000 次免费调用）

# 或者直接在启动前设置
export DASHSCOPE_API_KEY="sk-xxxxx"

## ⚠️ 注意事项

### 1. API 费用
- **Tavily**：免费版有次数限制，超出需付费
- **通义万相**：按次数收费，注意成本控制

### 2. 响应时间
- **搜索**：通常 1-3 秒
- **图像生成**：通常 10-30 秒，较慢

### 3. 错误处理
- 如果 API 不可用，工具会自动禁用
- 不会影响机器人的其他功能
- 日志中会有明确提示

### 4. 建议配置
- 建议先配置 **Tavily 搜索**（免费额度大，很实用）
- **图像生成**可选，按需配置

## 🎁 额外优化建议

### 1. 添加使用统计

在工具类中添加调用计数，监控 API 使用量：

```python
self.call_count = 0

async def execute(...):
    self.call_count += 1
    logger.info(f"📊 今日第 {self.call_count} 次调用")
    # ...
```

### 2. 缓存搜索结果

对相同查询在短时间内返回缓存结果，节省 API 调用：

```python
self.cache = {}  # {query: (result, timestamp)}

if query in self.cache:
    result, timestamp = self.cache[query]
    if time.time() - timestamp < 300:  # 5分钟内
        return result
```

### 3. 图像生成队列

限制同时生成的图片数量，避免资源浪费：

```python
self.generating = False

if self.generating:
    return ToolResult(
        success=False,
        message="已有图片正在生成中，请稍后..."
    )
```
