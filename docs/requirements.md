# zhinai-bot-v3 需求文档

## 📋 项目概述

### 项目目标
创建一个基于 LangChain + LangGraph 的新一代 QQ 机器人，具备：
- 强大的推理能力（ReAct Agent）
- 标准化的工具调用系统
- 轻松集成 NoneBot 插件商店的插件
- 保留 new-bot 的记忆、情感、角色扮演能力

### 核心价值主张
- **工具调用成功率**: 从 ~70% 提升到 >95%
- **可用工具数量**: 从 17 个扩展到 >100 个
- **新工具集成时间**: 从 ~2 小时缩短到 <5 分钟
- **复杂任务完成率**: 从 ~50% 提升到 >80%

## 🎯 功能需求

### FR-1: 双层 Agent 架构

#### FR-1.1 外层 RoleAgent（角色代理）
**优先级**: P0  
**描述**: 负责记忆、情感、角色扮演等高层功能

**功能点**:
- 长期记忆管理（基于 LangChain Memory）
- 情感状态追踪（继承 new-bot 的情感系统）
- 角色人设维护（Prompt 模板管理）
- 对话上下文管理
- 用户关系管理

**输入**: 用户消息 + 历史上下文  
**输出**: 增强后的消息 + 角色状态

#### FR-1.2 内层 ReActAgent（推理代理）
**优先级**: P0  
**描述**: 负责推理、规划、工具调用

**功能点**:
- 思维链推理（Chain-of-Thought）
- 工具选择与调用
- 多步骤任务规划
- 错误处理与重试
- 结果验证

**输入**: RoleAgent 的输出  
**输出**: 最终回复 + 工具调用结果

---

### FR-2: 标准化工具系统

#### FR-2.1 工具注册与管理
**优先级**: P0  
**描述**: 统一的工具注册和管理机制

**功能点**:
- 基于 LangChain Tool 的标准接口
- 自动工具发现（扫描 tools/ 目录）
- 工具元数据管理（名称、描述、参数 Schema）
- 工具分类与标签
- 工具启用/禁用控制

#### FR-2.2 NoneBot 插件适配
**优先级**: P1  
**描述**: 将 NoneBot 插件转换为 LangChain Tool

**功能点**:
- 插件自动扫描
- 指令式插件转换（/command → Tool）
- 事件监听器转换（on_message → Tool）
- 参数映射（NoneBot Args → Tool Schema）
- 权限控制继承

**示例**:
```python
# NoneBot 插件
@on_command("天气")
async def weather(city: str):
    return f"{city}的天气是..."

# 转换为 Tool
WeatherTool(
    name="get_weather",
    description="查询指定城市的天气",
    args_schema={"city": {"type": "string"}}
)
```

#### FR-2.3 MCP 工具集成
**优先级**: P2  
**描述**: 支持 Model Context Protocol 工具

**功能点**:
- MCP 服务器连接
- MCP 工具自动注册
- 参数类型转换
- 异步调用支持

### FR-3: 工作流引擎

#### FR-3.1 LangGraph 工作流
**优先级**: P1  
**描述**: 基于 LangGraph 的复杂工作流支持

**功能点**:
- 状态图定义（StateGraph）
- 条件分支（Conditional Edges）
- 循环与迭代
- 子图嵌套
- 工作流可视化

#### FR-3.2 预定义工作流模板
**优先级**: P2  
**描述**: 常见任务的工作流模板

**模板列表**:
- 信息搜索 → 总结 → 回复
- 多步骤任务规划 → 执行 → 验证
- 数据收集 → 分析 → 可视化
- 定时任务调度

---

### FR-4: 记忆系统

#### FR-4.1 短期记忆
**优先级**: P0  
**描述**: 对话上下文管理

**功能点**:
- 基于 ConversationBufferMemory
- 滑动窗口（最近 N 条消息）
- Token 限制管理
- 自动摘要压缩

#### FR-4.2 长期记忆
**优先级**: P1  
**描述**: 持久化的用户记忆

**功能点**:
- 向量数据库存储（Chroma/FAISS）
- 语义检索
- 记忆重要性评分
- 定期记忆整理

#### FR-4.3 情感记忆
**优先级**: P1  
**描述**: 继承 new-bot 的情感系统

**功能点**:
- 情感值追踪（好感度、亲密度等）
- 情感历史记录
- 情感触发事件
- 情感衰减机制

---

### FR-5: 可观测性

#### FR-5.1 LangSmith 集成
**优先级**: P1  
**描述**: 完整的调用链追踪

**功能点**:
- 自动 Trace 记录
- 工具调用监控
- 性能分析
- 错误追踪
- 成本统计

#### FR-5.2 本地日志
**优先级**: P0  
**描述**: 结构化日志系统

**功能点**:
- 分级日志（DEBUG/INFO/WARNING/ERROR）
- 日志轮转
- 敏感信息脱敏
- 日志查询接口

---

### FR-6: 配置管理

#### FR-6.1 环境配置
**优先级**: P0  
**描述**: 灵活的配置系统

**功能点**:
- .env 文件支持
- 配置验证
- 配置热加载
- 多环境支持（dev/prod）

#### FR-6.2 工具配置
**优先级**: P1  
**描述**: 工具级别的配置

**功能点**:
- 工具启用/禁用
- 工具参数默认值
- 工具调用限流
- 工具权限配置

## 🔧 非功能需求

### NFR-1: 性能
- 平均响应时间 < 3 秒
- 工具调用延迟 < 500ms
- 支持并发 10+ 用户

### NFR-2: 可靠性
- 工具调用成功率 > 95%
- 系统可用性 > 99%
- 自动错误恢复

### NFR-3: 可扩展性
- 新工具集成 < 5 分钟
- 支持 100+ 工具
- 插件热加载

### NFR-4: 可维护性
- 代码覆盖率 > 80%
- 完整的 API 文档
- 清晰的架构文档

### NFR-5: 安全性
- API Key 加密存储
- 工具调用权限控制
- 敏感信息过滤

## 📦 技术栈

### 核心框架
- **NoneBot2**: 2.3.3+ (QQ 机器人框架)
- **LangChain**: 1.1.0+ (Agent 框架)
- **LangGraph**: 1.0.0+ (工作流引擎)
- **LangSmith**: 最新版 (可观测性)

### 数据存储
- **SQLite**: 本地数据库
- **Chroma/FAISS**: 向量数据库
- **Redis**: 缓存（可选）

### LLM 提供商
- **DashScope (通义千问)**: 主要 LLM
- **DeepSeek**: 备用 LLM
- **OpenAI**: 兼容接口

### 开发工具
- **Python**: 3.10+
- **Poetry**: 依赖管理
- **Pytest**: 测试框架
- **Black**: 代码格式化
