# 机械臂小车配置指南

## 📋 概述

本功能让机器人可以远程控制农田机械臂小车系统，包括：
- 移动小车
- 控制机械臂
- 控制抓手
- 执行预设动作（拔草、播种、完整循环）
- 查看系统状态
- 重置系统

---

## ⚙️ 配置步骤

### 1. 服务器地址配置

在 `.env` 文件中添加（或修改）机械臂服务器的地址：

```bash
# 机械臂服务器地址（默认：http://localhost:8080）
ROBOTIC_ARM_API_URL=http://localhost:8080
```

### 2. 从局域网访问

如果你的机械臂服务器运行在其他电脑上，需要修改为局域网IP：

```bash
# 示例：从其他设备访问
ROBOTIC_ARM_API_URL=http://192.168.1.100:8080
```

### 3. 重启机器人

配置完成后，重启机器人使配置生效：

```bash
cd new-bot
bash stop.sh
bash start.sh
```

## 🔧 API端点参考

机器人内部调用的API端点：

| 动作 | API端点 | 方法 |
|------|---------|------|
| 获取状态 | `/api/status` | GET |
| 重置系统 | `/api/reset` | POST |
| 移动小车 | `/api/cart/move` | POST |
| 移动机械臂 | `/api/arm/move` | POST |
| 控制抓手 | `/api/gripper` | POST |
| 执行拔草 | `/api/action/pull_grass` | POST |
| 执行播种 | `/api/action/plant_seed` | POST |
| 完整循环 | `/api/action/full_cycle` | POST |

## 📊 参数说明

### 小车移动参数

```json
{
  "action": "move_cart",
  "x": 0.5,        // X轴位置（-1.5 ~ 1.5）
  "z": 0.3,        // Z轴位置（-1.5 ~ 1.5）
  "duration": 1.5  // 动画时长（秒，可选，默认1.5）
}
```

### 机械臂移动参数

```json
{
  "action": "move_arm",
  "shoulder": 45,   // 肩关节角度（-180 ~ 180，可选）
  "elbow": -60,     // 肘关节角度（-180 ~ 180，可选）
  "wrist": 30,      // 腕关节角度（-180 ~ 180，可选）
  "duration": 1.0   // 动画时长（秒，可选，默认1.0）
}
```

### 抓手控制参数

```json
{
  "action": "control_gripper",
  "gripper_state": "open"  // "open" 或 "closed"
}
```

### 执行动作参数

```json
{
  "action": "pull_grass",  // 或 "plant_seed"
  "cell": 5                // 格子索引（0-15，可选，默认0）
}
```

## ⚠️ 注意事项

1. **网络要求**：
   - 机械臂服务器必须在局域网内可访问
   - 确保防火墙允许相应端口（默认8080）

2. **服务器状态**：
   - 如果服务器未启动或不可访问，工具会返回错误
   - 机器人会如实告诉用户操作失败

3. **并发控制**：
   - 机器人一次只能执行一个动作
   - 等待一个动作完成后再执行下一个

4. **安全提示**：
   - 当前版本无身份验证
   - 建议仅在内网使用
   - 生产环境需添加认证机制

## 📞 故障排除

### 1. 工具未注册

检查日志：
```bash
tail -f logs/bot.log | grep "已注册工具"
```

如果看不到 `control_robotic_arm`，可能是导入错误。

### 2. 连接超时

检查服务器是否运行：
```bash
curl http://localhost:8080/api/status
```

如果无法连接，检查：
- 服务器是否启动
- 地址是否正确
- 防火墙设置

### 3. 操作失败

检查服务器日志，查看具体错误原因。
