## 🛠️ 新增工具

### 1. ReadProjectFileTool（读取项目文件）
- **功能**：读取项目中的文件内容
- **使用场景**：查看代码、配置、文档
- **返回**：文件内容 + 基本信息（大小、行数）

### 2. WriteProjectFileTool（写入项目文件）
- **功能**：创建或修改项目文件
- **权限**：仅管理员（QQ: 1446437177）
- **安全**：所有操作记录到审计日志

### 3. ListProjectFilesTool（列出项目文件）
- **功能**：列出目录中的文件
- **特性**：支持模式匹配、递归列出
- **返回**：文件列表（按目录分组）

### 4. SearchInFilesTool（搜索文件内容）
- **功能**：在项目文件中搜索内容
- **特性**：支持正则表达式、限制结果数量
- **返回**：文件名 + 行号 + 匹配内容

### 5. GetDirectoryTreeTool（获取目录树）
- **功能**：获取目录树结构
- **特性**：支持控制深度
- **返回**：树形结构
