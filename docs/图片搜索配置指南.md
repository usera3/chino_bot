# 🖼️ 图片搜索配置指南

## 功能说明

你的机器人现在支持**两种**图片搜索方式：

1. **Google Images** (SerpAPI) - 优先使用 ⭐⭐⭐⭐⭐
2. **Unsplash** - 备用方案 ⭐⭐⭐

机器人会**智能降级**：优先使用 Google Images，如果不可用或失败，自动降级到 Unsplash。

---

## 🥇 方案一：SerpAPI (推荐)

### 为什么推荐？
- ✅ **真实的 Google Images 结果** - 就像在浏览器搜索一样
- ✅ **搜索范围广** - 能找到任何类型的图片
- ✅ **支持中文搜索** - 完美支持中文关键词
- ✅ **每月 100 次免费** - 够个人使用

### 获取 SerpAPI 密钥

#### 第一步：注册账号

1. 访问：https://serpapi.com
2. 点击 **"Register"** 或 **"Sign Up"**
3. 使用邮箱注册或 Google 账号登录

#### 第二步：获取 API 密钥

1. 登录后，进入 **Dashboard**
2. 在页面顶部找到 **"API Key"**
3. 复制你的 API Key（格式：长串字符）

#### 第三步：配置到机器人

```bash
cd /Users/mozi100/PycharmProjects/chino_bot/new-bot

# 编辑配置文件
nano .env

# 找到这一行：
# SERPAPI_KEY=""

# 修改为（替换成你的实际密钥）：
# SERPAPI_KEY="你的API密钥"

# 保存：Ctrl+X, Y, Enter

# 重启机器人
./stop.sh && ./start.sh
```

**或者使用命令**：

```bash
cd /Users/mozi100/PycharmProjects/chino_bot/new-bot

# 直接修改（替换 YOUR_KEY）
sed -i '' 's/SERPAPI_KEY=""/SERPAPI_KEY="YOUR_KEY"/' .env

# 重启
./stop.sh && ./start.sh
```

### 免费额度

- ✅ **每月 100 次搜索**
- ✅ 无需信用卡
- ✅ 永久免费

## 🥈 方案二：Unsplash (备用)

### 特点
- ✅ **高质量专业摄影** - 适合找风景、人物等艺术照
- ✅ **每小时 50 次** - 更高的免费额度
- ⚠️ **范围有限** - 只有专业摄影作品，找不到表情包、截图等

### 获取 Unsplash 密钥

#### 第一步：注册开发者账号

1. 访问：https://unsplash.com/developers
2. 点击 **"Register as a developer"**
3. 登录或注册账号

#### 第二步：创建应用

1. 进入 **"Your apps"**
2. 点击 **"New Application"**
3. 接受服务条款
4. 填写应用信息：
   - **Application name**: `QQ ChatBot`
   - **Description**: `A chatbot for QQ`
5. 提交后复制 **Access Key**

#### 第三步：配置到机器人

```bash
cd /Users/mozi100/PycharmProjects/chino_bot/new-bot

nano .env

# 找到这一行：
# UNSPLASH_ACCESS_KEY=""

# 修改为：
# UNSPLASH_ACCESS_KEY="你的Access_Key"

# 保存并重启
./stop.sh && ./start.sh
```

## 🐛 故障排查

### 问题 1：提示"图片搜索功能不可用"
**原因**：API 密钥未配置或配置错误

**解决**：
```bash
# 检查配置
cd /Users/mozi100/PycharmProjects/chino_bot/new-bot
cat .env | grep -E "(SERPAPI|UNSPLASH)"

# 应该显示非空的密钥
# SERPAPI_KEY="xxxxx"  ← 不是空的
```

### 问题 2：搜索失败或返回错误
**原因 1**：API 密钥无效
- 检查密钥是否正确复制
- 尝试重新生成密钥

**原因 2**：超过免费额度
- SerpAPI: 每月 100 次
- Unsplash: 每小时 50 次

**解决**：等待额度重置，或配置备用方案

### 问题 3：找不到某些类型的图片
**可能原因**：使用了 Unsplash（只有专业摄影）

**解决**：配置 SerpAPI，它能搜索所有类型的图片
