## 🔌 技术架构

### 技术栈

```
前端框架:
├── React Native 0.76.x    (原生渲染)
├── Expo SDK 52.x          (开发框架)
├── React Hooks            (状态管理)
└── StyleSheet             (样式系统)

网络通信:
├── Axios 1.7.x            (HTTP 请求)
├── Socket.IO 4.8.x        (WebSocket)
└── Fetch API              (备用)

手势处理:
└── React Native Gesture Handler 2.20.x

开发工具:
├── Expo CLI               (开发服务器)
├── EAS Build              (云端打包)
└── Metro Bundler          (模块打包)
```

### 通信架构

```
┌──────────────┐                      ┌──────────────┐
│              │  HTTP REST API       │              │
│  移动 APP    │ ◄──────────────────► │  服务器      │
│  (手机)      │                      │  (7070)      │
│              │  WebSocket Events    │              │
│              │ ◄──────────────────► │              │
└──────────────┘                      └──────────────┘
     │                                        │
     │                                        │
     └──────── 同一 WiFi / 远程连接 ─────────┘
```

### 数据流

```
用户操作 → React State 更新
         ↓
    HTTP POST 请求
         ↓
    服务器执行动作
         ↓
    WebSocket 广播事件
         ↓
    APP 接收并更新 State
         ↓
    UI 重新渲染
         ↓
    网页动画同步
```

### API 设计

#### REST API

```javascript
// 获取状态
GET /api/status
Response: {
  cart: { x, z },
  arm: { shoulder, elbow, wrist },
  gripper: { is_open },
  current_action
}

// 执行动作
POST /api/action
Body: {
  action: "move_cart" | "reset" | "pull_grass" | ...,
  ...params
}
Response: {
  status: "success" | "error",
  message: "..."
}
```

#### WebSocket Events

```javascript
// 客户端监听
socket.on('connect')         // 连接建立
socket.on('status_update')   // 状态更新
socket.on('action')          // 动作执行
socket.on('cart_move')       // 小车移动
socket.on('arm_move')        // 机械臂移动
socket.on('gripper_update')  // 抓手更新
socket.on('system_reset')    // 系统重置
```
