## 🛠️ LangChain 工具

### 1. PreviewChangesTool

**工具名称**：`preview_code_changes`

**功能**：
- 对比原文件和新内容
- 生成 unified diff
- 显示添加/删除的行数
- **不会修改文件**

**输入参数**：
- `file_path` (str)：文件路径
- `new_content` (str)：新的文件内容

**输出格式**：
```
📝 预览代码更改: core/butler.py
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📊 更改统计:
  ✅ 添加: 5 行
  ❌ 删除: 3 行
  📍 修改块: 2 个

🔍 详细对比:
```diff
--- a/core/butler.py
+++ b/core/butler.py
@@ -10,3 +10,5 @@
 def process():
-    pass
+    # 新的实现
+    return True
```

💡 提示:
  - 使用 apply_code_changes 应用更改
  - 会自动创建备份文件
```
