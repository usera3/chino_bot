## 📞 问题排查

### 问题 1：路径验证失败
```python
# 检查路径
print(os.path.realpath(path))
print(PROJECT_ROOT)

# 确保路径在项目内
assert path.startswith(PROJECT_ROOT)
```

### 问题 2：命令执行失败
```python
# 检查命令白名单
print(SAFE_COMMANDS)

# 手动测试命令
subprocess.run(command, shell=True, capture_output=True)
```

```python
# 检查用户权限
print(user_id in ADMIN_USERS)

ADMIN_USERS.append("your_qq_id")
```
