# 高德地图工具配置指南

## 📖 功能介绍

高德地图工具为机器人提供地理位置服务：
- 🔍 **地点搜索**：搜索餐厅、咖啡店、超市、医院等
- 📍 **周边搜索**：查找附近的地点
- 🗺️ **地址查询**：获取详细地址信息

## 🔑 获取高德地图 API Key

### 1. 注册开发者账号
1. 访问：https://lbs.amap.com/
2. 点击右上角「注册/登录」
3. 使用手机号或邮箱注册账号

### 2. 创建应用
1. 登录后进入「控制台」：https://console.amap.com/dev/key/app
2. 点击「创建新应用」
3. 填写应用信息：
   - 应用名称：`智乃机器人`（随意）
   - 应用类型：`Web服务`

### 3. 添加 Key
1. 在应用下点击「添加Key」
2. 填写信息：
   - Key名称：`机器人API`（随意）
   - 服务平台：选择 **「Web服务」**
3. 点击「提交」
4. 复制生成的 **Key**

### 4. 免费额度
- ✅ **每天免费调用量**：5,000次
- ✅ **个人开发者认证后**：30,000次/天
- ✅ 对于个人机器人使用完全足够

## ⚙️ 配置步骤

### 1. 添加 API Key 到环境变量

编辑 `.env` 文件：

```bash
cd /Users/mozi100/PycharmProjects/chino_bot/new-bot
```


## 🔧 API 参数说明

### 工具名称
- `search_nearby`

### 输入参数
- `keyword` (必需): 搜索关键词
  - 示例：`咖啡店`、`餐厅`、`医院`、`超市`
- `city` (可选): 城市名称
  - 示例：`北京`、`上海`、`深圳`

### 返回结果
```json
{
  "success": true,
  "data": {
    "keyword": "咖啡店",
    "city": "北京",
    "results": [
      {
        "name": "星巴克（国贸店）",
        "address": "北京市朝阳区建国路1号",
        "distance": "523",
        "type": "餐饮服务;咖啡厅"
      }
    ],
    "count": 5
  },
  "message": "🗺️ 找到 5 个'咖啡店'相关地点：..."
}
```

### 住宿服务
- 酒店、宾馆、青年旅社等

### 休闲娱乐

## ⚠️ 注意事项

### 1. API 限制
- 每天免费调用 5,000 次
- 超过限制后需要付费或等待第二天重置

### 2. 搜索精度
- 如果没有提供用户位置，默认返回相对位置或城市中心附近
- 更精确的搜索需要提供经纬度坐标（暂未实现）

### 3. 结果数量
- 默认返回 5 条结果
- 可以根据需要调整 `offset` 参数

## 🐛 常见问题

### 1. 提示"API密钥未配置"
**原因**：`.env` 文件中没有配置 `AMAP_API_KEY`  
**解决**：按照上述步骤添加 API Key

### 2. 搜索无结果
**原因**：
- 关键词太宽泛或太具体
- 城市信息不准确
- 该地区确实没有相关地点

**解决**：
- 尝试更换关键词
- 指定明确的城市
- 查看日志中的详细错误信息

### 3. API 调用失败
**原因**：
- API Key 无效或过期
- 网络连接问题
- 超过每日调用限制

**解决**：
```bash
# 查看日志
tail -50 logs/bot.log | grep "高德地图"

# 验证 API Key
curl "https://restapi.amap.com/v3/place/text?keywords=咖啡&key=你的API_Key"
```
