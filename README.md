# 新机器人

独立的QQ机器人项目，使用NoneBot2框架开发。

## 特点

- 🎯 完全独立，不影响旧机器人运行
- 🔄 共享虚拟环境，节省资源
- 💬 基本聊天功能
- 📝 简洁的代码结构
- 🚀 易于扩展

## 快速开始

### 1. 配置

首次使用需要配置 `.env` 文件：

```bash
# 启动脚本会自动从 .env.example 复制
./start.sh
```

编辑 `.env` 文件，设置必要的参数：
- `HOST`: 监听地址（默认 127.0.0.1）
- `PORT`: 监听端口（默认 8082，注意不要和旧机器人冲突）
- `SUPERUSERS`: 超级用户QQ号列表

### 2. 配置NapCat

在NapCat中添加新的反向WS连接：
- 地址: `ws://127.0.0.1:8082/onebot/v11/ws`

### 3. 启动

```bash
# 启动机器人
./start.sh

# 查看状态
./status.sh

# 查看日志
tail -f logs/bot.log

# 停止机器人
./stop.sh
```

```
    └── bot.log
```

## 功能说明

### 基本聊天

在群聊或私聊中@机器人，它会根据关键词回复：

- "你好" / "hi" → 问候
- "再见" / "拜拜" → 告别
- "谢谢" → 感谢回复
- "天气" → 天气相关
- 其他内容 → 通用回复

### 扩展功能

需要添加新功能时，在 `plugins/` 目录下创建新的插件文件即可。

## 注意事项

⚠️ **重要**：
1. 本机器人与旧机器人完全独立
2. 不要修改旧机器人的任何文件
3. 确保端口号不冲突（新: 8082，旧: 8080）
4. 使用相同的虚拟环境（`/Users/mozi100/PycharmProjects/chino_bot/.venv`）
