# Code of Conduct

Chino Bot welcomes contributions from people who are here to build useful,
responsible agent software.

Please be respectful, constructive, and security-minded. Do not use issues,
pull requests, or discussions to publish private credentials, personal account
details, harassment, spam, or instructions for abusing QQ, OneBot, API
providers, or other services.

Maintainers may remove content or block participants who make the project
unsafe for users or contributors.
